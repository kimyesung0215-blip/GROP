# GROP

내가 해 온, 그리고 앞으로 할 프로젝트 활동을 한곳에 모으는 지식 보관소.
최종 목적은 포트폴리오를 이 볼트에서 **생성**하는 것이다.

## 원칙

- **대화는 작업대, 볼트가 기억이다.** Claude·다른 AI와의 대화는 원자료일 뿐이고, 남겨야 할 것만 여기로 옮긴다.
- **여기가 유일한 진실이다.** 같은 내용을 Notion·대화·다른 곳에 원본으로 두지 않는다.
- **구조는 내용이 생길 때 만든다.** 빈 폴더와 템플릿을 미리 깔지 않는다.

## 구조

```
GROP/
├── README.md        ← 이 파일. 전체 목차
├── AGENTS.md        ← AI 에이전트가 이 볼트를 다루는 규칙
├── docs/
│   └── decisions.md ← 볼트 자체에 대한 결정 기록
├── projects/        ← 프로젝트별 폴더 (이주할 때 하나씩 생성)
│   └── <slug>/
│       ├── README.md     ← 개요·역할·기간·상태·결과
│       └── decisions.md  ← 결정 원장
└── private/         ← 비공개 영역. 별도 비공개 저장소, 공개 쪽 git에서 제외
```

## 운영 규칙

- **대화 제목**: 기록 대상이면 `[프로젝트] 주제` 형식. 일회성 질문은 태그 없음.
- **세션 시작**: 첫 메시지에 "어떤 프로젝트, 오늘 목표" 한 줄.
- **세션 종료**: "정리" → 새 결정과 진행 상황을 해당 프로젝트 파일에 추가.
- **승격 기준**: 같은 주제로 두 번째 세션이거나 산출물이 나오면 Claude 프로젝트와 `projects/<slug>/`를 함께 만든다.
- **이름**: 같은 대상은 늘 같은 이름으로 부른다. 파일명과 결정 제목에 검색될 단어를 넣는다.
- **링크**: 공개↔비공개 양방향 링크 허용. 단, `private/` 파일명은 중립적으로 짓는다(사람 이름·평가·민감한 상황은 본문에만).
