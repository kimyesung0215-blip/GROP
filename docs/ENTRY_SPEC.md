# ENTRY_SPEC — 결정 기록 기준

GROP의 모든 결정 원장(`docs/decisions.md`, `projects/<slug>/decisions.md`)은 이 기준을 따른다.
에이전트는 이 파일을 작업 프롬프트에 복제하지 않고, 매번 여기서 읽는다.

기록 단위는 세션이 아니라 **결정 하나**다. 목적은 같은 갈림길을 다시 고민하지 않는 것,
그리고 나중에 보고서·컨택·포트폴리오에 쓸 때 근거와 주체를 추적하는 것이다.

---

## 1. 형식

필수 5줄:

```markdown
### [탐색토큰] 한 줄 결론
근거와 버린 대안. 원문에 버린 대안이 없으면 "버린 대안: 원문에 기록 없음".
주체: …
채택: …
출처: …
```

선택 (해당될 때만):

```markdown
검증: …          ← 수치·계산·실험이 들어간 항목만
날짜: …          ← 원문에서 결정 시점이 확인될 때만. 이관일로 대신하지 않는다
관련: [토큰]      ← 정정·변경하는 이전 항목이 있을 때
```

- **탐색토큰**: 검색될 고유어 하나. 부품명·수치·고유 개념 (`[MG90S]`, `[0.3mm]`, `[InMoov]`). 같은 원장 안에서 겹치지 않게.
- **자립성**: 항목 하나가 다른 항목 없이 읽혀야 한다. 정의 없는 용어는 출처에서 뜻을 확인할 수 있을 때만 풀어 쓰고, 못 하면 "용어 정의 확인필요".

## 2. 어휘

| 칸 | 값 | 비고 |
|---|---|---|
| 주체 | 본인 / AI 제안 / 팀 / 외부 / 확인필요 | 제안자와 채택자가 다르면 `X 제안·본인 채택`. 비워두지 않는다 |
| 채택 | 제안 / 채택 / 보류 / 철회 / 확인필요 | 사용자의 수락이 원문에 있어야 `채택` |
| 검증 | 실측 / 계산 / 문헌·사양 / 검증대기 / 확인필요 | 근거가 섞이면 각각 적는다 |

주체와 채택은 다른 질문이다. "AI가 냈고 본인이 받아들였다"는 `주체: AI 제안·본인 채택` + `채택: 채택`.
AI가 냈는데 수락 기록이 없으면 `주체: AI 제안` + `채택: 제안`.

## 3. 출처의 신뢰 순서

1. 대화 원문
2. 프로젝트 지식 베이스의 파일
3. 프로젝트 메모리 (AI가 요약했지만 사용자 발언으로 표시된 것)
4. AI 압축 요약

- 낮은 순위만으로 주체·채택을 확정하지 않는다. 원문에 수락 기록이 없으면 프로젝트 메모리도 찾아보고, 메모리를 근거로 썼으면 출처에 그렇게 적는다.
- 두 모델이 같은 말을 해도 교차검증이 아니다. 같은 오염원일 수 있다.
- `확인필요` 항목은 보고서·컨택에 쓰기 직전에 그 항목만 확인한다. 미리 전부 풀 필요는 없다.

## 4. 기록하는 것 / 안 하는 것

기록한다:
- 선택지가 둘 이상이었고 하나를 골랐을 때
- 이전 결정을 뒤집거나 철회했을 때 (판단 오류 기록은 특히 남긴다)
- 수치·모델명이 확정됐을 때, 새 제약이 드러났을 때
- 검증 상태가 바뀌었을 때
- 미해결로 두기로 의식적으로 정했을 때

기록하지 않는다:
- 설명·학습 내용, 진행 로그, 산출물 본문 (코드·일정표·부품표는 별도 파일)
- 아직 고르지 않은 선택지 나열

## 5. 정정

- 첫 커밋 이후의 항목은 고치지 않는다. 정정 항목을 새로 추가하고 `관련:`으로 이전 항목을 가리킨다.
- 같은 결정의 반복 언급은 중복 추가하지 않는다.
- 이전 설계가 바뀌었다는 이유만으로 관련 결정을 모두 철회로 추정하지 않는다.

## 6. 구 형식 대응

다음 원장은 이 기준이 생기기 전에 작성되어 구 형식을 쓴다. 다시 쓰지 않고 아래처럼 읽는다.

- `projects/robot-hand/decisions.md` (2026-10-10 이관분 47건)
  - `상태: 이론값` ≈ `검증: 계산` 또는 `문헌·사양` (어느 쪽인지 미구분)
  - `상태: 검증됨` ≈ `검증: 실측`
  - `상태: 폐기` ≈ `채택: 철회`
  - `주체: AI 제안·채택 확인필요` ≈ `주체: AI 제안` + `채택: 확인필요`
- `docs/decisions.md`의 D001~D009는 `- 결정: / - 주체:` 목록 형식. 이후 항목은 이 기준을 따른다.
