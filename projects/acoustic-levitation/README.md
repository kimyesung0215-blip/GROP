# 한일공동수업 음향 부양 프로젝트

40kHz 초음파 트랜스듀서로 작은 시료를 공중에 띄우는 음향 부양 장치를 직접 만들고, 두 차수에 걸쳐 실험한다.

- **33차 (1학기)**: 공개 모델 기반 곡면 배열 장치(2·18·72개)로 "인가 전압 ↔ 부양 가능 질량" 관계를 측정.
- **34차 (2학기)**: 98채널(7×7 상하 대향) 독립 위상 제어 장치를 설계·제작해, 띄운 시료를 X·Y·Z로 옮기는 것이 목표.
- 두 차수를 잇는 질문(본인): 1차는 장치가 **지탱할 수 있는 무게의 상한**, 2차는 장치가 **물체를 제어할 수 있는 정도의 상한**. 장치의 쓰임은 "접촉을 없애 변인을 근본에서 통제하는 실험 보조 기구".

결정 원장: [decisions.md](decisions.md) · 원자료 대응표: `private/projects/acoustic-levitation/sources.md`

## 역할

3인 팀(본인 팀장). 주제 선정과 기본 조사·선행연구는 3명이 함께 했고, 팀원은 본인이 정한 역할을 수행했다. 팀원별 세부 분담은 비공개 영역에 둔다.

| 영역 | 본인 몫 |
|---|---|
| 33차 장치 | 공개 모델 STL 1.6배 확대, 3D 출력, 회로·배선, z축 조절 구조(공동), 납땜(공동). 모델 선정은 팀원 |
| 33차 실험 | 2단계 구조 제안, 디스크 표준 시료 아이디어·설계·출력·보관 케이스. 측정·데이터 정리는 팀원 주도 |
| 33차 분석·문서 | 그래프 작성, 회귀 분석(공동), 보고서 종합 작성 |
| 시뮬레이터 | AcousticSimV2 — 문제 인식부터 개발까지 단독 |
| 전문가 컨택 | 실험 외 활동, 단독 (해외 2명, 국내 6명) |
| 34차 | 장치 구조·PCB 설계와 검증·발주·부품 구매·펌웨어·프레임 CAD·실험 계획과 발표 전담. 오실로스코프 계측은 팀원과 공동 |

AI는 계산·코드 초안·검토를 보조했다. 각 결정의 제안자와 채택자는 원장에 구분해 적었다.

## 33차 — 전압-질량 관계 (2026-03 ~ 07)

주제 상의와 재료 발주가 길어 실제 제작·실험은 시작보다 늦게 들어갔다.

### 장치

| 구분 | 2개 | 18개 | 72개 (BigLev ×1.6) |
|---|---|---|---|
| 배치 | 1개씩 대향 | 반구당 중앙 1 + 8각 링 | 반구당 6·12·18 3중 링 |
| 반구간 거리 | 17.2 mm | 약 100 mm | 170 mm (본인 실측) |
| 곡률반경 | — | 약 60 mm (STL 분석) | 약 104 mm ([곡률104]) |
| L298N 모듈 | 1 | 1 | 6 (12개씩 독립 그룹) |

공통: V40AN16T(Φ16, 40kHz), Arduino Nano 타이머로 40kHz 생성, 상하 반전 신호, 0~30V 가변 DC(멀티미터 실측값 사용).

### 실험과 결과

- **실험 1 — 재료 치환**: 비슷한 부피에서 재료(밀도)를 바꿈. 18개 장치 7종, 2개 장치 2종. 재료마다 표면·형상도 달라져 질량만의 효과를 분리하기 어려웠다 → 실험 2로.
- **실험 2 — 디스크 표준화**: 같은 3D 출력 재료로 디스크 반지름(1·2·4 mm)과 두께를 바꿈. 세 장치 모두.
- 성공 기준 3초 유지, 조건당 7회 측정 중 2~6차 5회 분석.

| 장치 | 기울기 a (V²/g) | R² | 30V 외삽 질량 | 5/5 반복 성공 최대 |
|---|---|---|---|---|
| 2개 | 64,262 | 0.689 | 0.014 g | 0.003 g |
| 18개 | 42,425 | 0.885 | 0.021 g | 0.007 g |
| 72개 | 12,693 | 0.891 | 0.071 g | 0.017 g |

- V²∝m은 18개·72개에서 근사적으로 성립하고, 저질량 전압 하한·2개 장치의 치수 민감성·외삽과 실측의 차이로 체계적으로 이탈한다.
- 장치끼리는 소자 수와 함께 곡률·간격·구동 그룹도 달라, 소자 수만의 효과로 해석하지 않는다. 2개↔18개 기울기 차이는 통계적으로 확정되지 않는다([2대18통계]).

### 시뮬레이터 AcousticSimV2

실험과 병행 개발(본인 단독). 점음원 음압장 → 원형 피스톤 지향성 → Gor'kov 포텐셜 → 중력 보정 유효 포텐셜 → 헤시안 안정성 → 도달 위상·결맞음 진단. 포획 위치와 장치별 상대 경향을 보는 보조 도구이며, 정량 정확도는 검증되지 않았다([시뮬정확도]).

### 후속 (2026-07 ~ 09)

- 72개 장치는 드라이버 소손·배선 분리·소자 이설로 재구성 불가 → 교수 피드백 검증은 시뮬레이션 단독 경로로 계획([재실험포기]). 세 기하 시뮬 실행은 미수행.
- 전문가 컨택: 해외 2명(08-04), 국내 6명(09-07) 발송, 1건 회신. 경위는 비공개 영역.

## 34차 — 98채널 위상배열 장치 (2026-08 ~, 진행중)

| 항목 | 값 |
|---|---|
| 배열 | 7×7 상하 대향, 98채널, V40AN16T, 피치 16.5 mm |
| 구동 | 채널당 TC4428A 차동(15V 레일, 소자 양단 30Vpp), 직렬저항 10Ω ×2 |
| 제어 | Arduino Mega 2560 ×2(보드당 49채널, 기판 밖 IDC 연결), π/5(36°) 10단계 위상 |
| 클럭 | 상판 4MHz → 하판 Timer5 외부 클럭 (벤치 주파수 일치까지 확인) |
| PCB | 2층 150×150 mm, REV13_FINAL, JLCPCB PCBA(SMD) + 트랜스듀서 수작업 |
| 프레임 | PLA, 상하판 간격 수동 조절 범위 60~180 mm, 가이드봉 Ø12 |
| 방사면 간격 | 미확정. 기록상 120 mm 잠정 |

진행: REV13_FINAL 주문 완료, 트랜스듀서 100개 추가 주문. 2학기 실험 계획 발표(속도 제한·이동 축 → 성공률·위치 오차) 단계. 실험은 심사 통과 후 진행.

## 파생 활동

- 수행평가 「위상차와 파동 합성의 수학적 원리 탐구」 — 장치 위치에 따라 효과가 달라지는 관찰에서 출발.
- 수학 심화 탐구 「맥놀이」 — Audacity 합성 파형 측정, f_b = 0.9936Δf (R² 0.99998)로 f_b = Δf 지지. 제출본은 본인 직접 작성 원본.
